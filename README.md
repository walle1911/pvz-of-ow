# PVZ-OF-OW

一个以 Godot 制作的《植物大战僵尸》同人改版项目。在熟悉的草坪防线之上，植物、僵尸与《守望先锋》角色相遇；这里既能体验关卡，也能进入开发者模式，亲手调整数值和制作关卡。

> 非官方、非商业同人项目，仅用于学习、研究与交流。

[项目演示](https://www.bilibili.com/video/BV1FKNJzUEpp) · [代码仓库](https://github.com/walle1911/pvz-of-ow) · QQ 群：1046565016

## 这是什么

PVZ-OF-OW 从原版《植物大战僵尸》的玩法出发，加入了 PVZ × Overwatch 的角色、机制与关卡内容。项目仍在持续制作：冒险模式、小游戏、解谜模式与生存模式已经具备基础功能与框架，后续会继续完善体验与内容。

你可以在项目中找到：

- 白天、夜晚、泳池、迷雾与屋顶等经典战场
- 植物、僵尸、卡牌、子弹、掉落物与状态效果
- PVZ × Overwatch 同人角色及其玩法设计
- 图鉴、花园、商店、存档等游戏系统
- 自定义关卡与数值调整功能

![开始菜单](readme_show/run_start_menu.png)

## 游玩与编辑

游戏内提供开发者模式。若你觉得某个数值或关卡设计不合心意，可以自行调整植物、僵尸的可开放参数，也可以编辑关卡内容；欢迎把它当作一套可以继续折腾的 PVZ 改版工具箱。

项目使用 Godot 4.6 系列开发，默认采用 GL Compatibility 渲染模式。主入口由 `project.godot` 配置，启动场景为 `scenes/main/00TitleLoadingScreen.tscn`。

## 获取与运行

本仓库主要提供代码与工程配置，并不包含完整的图片、字体、音乐、音效等素材。因为 `assets/` 中的内容受版权与授权范围限制，直接克隆仓库后可能无法完整启动，这是预期情况。

如需运行完整工程，请自行准备拥有合法使用权的对应素材，并按照项目所需的相对路径放入根目录的 `assets/` 中。有关项目资源说明及网盘信息，可在 Bilibili 搜索 **瓦尔泽亚1582** 查询；下载、使用或再分发前，请自行确认授权与所在地法律要求。

使用 Godot 4.6.x 导入仓库根目录的 `project.godot` 后，等待资源扫描完成即可启动项目。缺少素材时出现 `Preload file ... does not exist` 或 `Failed loading resource` 等报错，通常表示资源尚未补齐。
