# 正式冒险关卡覆盖数据

在地图工坊载入“成品关卡”并点击“应用正式”后，会在本目录生成对应的 JSON：

- 普通线：`adventure_1_1.json` 至 `adventure_5_10.json`，覆盖白天、夜晚、泳池、雾夜、屋顶五个世界
- 棋盘格线：`chess_1_1.json` 至 `chess_1_10.json`

正式选关优先读取这里的 JSON；没有对应文件时，继续使用 `adventure_level_presets.gd` 中的内置默认生成规则。

覆盖数据不仅包含波次和僵尸配置，还保存正式选关显示的 `name` 以及通关新卡奖励 `rewardPlant`；`rewardPlant = -1` 表示本关不掉落新卡。

普通冒险线的角色池按原版角色槽位和首次出现节奏生成：存在 OW 改版的槽位只使用 OW 版本，尚未改版的槽位回退到原版角色；OW 独占角色会插入原版特殊关或屋顶升级阶段。棋盘格线仍保持纯原版池。
