# 开发者冒险关卡覆盖数据

在地图工坊载入“成品关卡”并点击“应用预设”后，会在本目录生成对应的 JSON：

- 普通线：`adventure_1_1.json` 至 `adventure_5_10.json`，覆盖白天、夜晚、泳池、雾夜、屋顶五个世界

这些 JSON 会被开发者模式“开始冒险吧”和工坊读取。工坊“编辑正式冒险关卡”中的“同步到正式模式”可以勾选关卡，并把已保存版本复制到 `data/formal_adventure_levels/`。普通模式只读取该正式快照目录中的 1-1 至 3-10；开发者模式仍保留五个世界供继续编辑，3-10 之后的关卡不会显示在正式模式中。

覆盖数据不仅包含波次和僵尸配置，还保存开发者关卡显示的 `name` 以及通关新卡奖励数组 `rewardPlants`；空数组表示本关不掉落新卡。旧的单值 `rewardPlant` 会自动迁移，并继续同步首张奖励用于兼容旧工具。

普通冒险线的角色池按原版角色槽位和首次出现节奏生成：存在 OW 改版的槽位只使用 OW 版本，尚未改版的槽位回退到原版角色；OW 独占角色会插入原版特殊关或屋顶升级阶段。
