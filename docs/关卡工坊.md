# 游戏内关卡工坊

## 给普通玩家

从主菜单点击“关卡工坊”后，会直接进入白天草坪编排场景。僵尸图鉴面板会从左侧滑入，占据屏幕约 47%，背景与视口右边缘对齐，右侧保留完整马路用于查看当前阶段已经选择的僵尸：

1. 左侧面板直接使用 `Almanac_ZombieBack.jpg`，按钮、弹窗和进度条只复用 `assets/image/Almanac/` 与 `assets/image/ui/` 中的现有素材；工坊全部文字统一使用 `方正少儿_GBK.ttf`。
2. 右下角进度条复用正式关卡的旗帜进度条素材，保持原始比例并仅做整体等比缩放。旗帜和波间在鼠标悬停时会预览升起或暗色区段，点击后才正式黄色选中。“选波间”和“＋旗帜”都是互斥模式，再点一次同一按钮可取消；波间持续时间决定区段长度，插旗会按落点拆分前后波间。
3. 旗帜波会在试玩时触发“一大波僵尸来袭”，并升起右下角进度条中的对应旗帜；波间阶段也可以正常配置和刷新僵尸。
4. 左侧直接读取 `AllCards.all_zombie_card_prefabs` 中的全部僵尸，并保持游戏现有卡牌外观。卡片采用每页 24 张、6 列×4 行的图鉴式分页，不会为了塞满一页而挤在一起。
5. 每次点击卡片都会打开石碑弹窗，用数值选择器直接设置该僵尸在当前阶段的出场数量；设置为 0 可以从当前阶段移除。
6. 右侧大马路沿用正式关卡开局展示逻辑，实例化正常大小的 `IsShow` 僵尸并在道路区域随机排布。预览最多显示 20 只，超过部分会显示数量提示；实际出生数量和路线不受预览上限影响。
7. 试玩时不会在阶段开始时一次生成全部僵尸，而是按照绝对时间表逐只生成并随机分排。
8. 切换进度条阶段时会恢复该阶段的预览。
9. 点击“试玩”，会直接使用当前自动保存的内容进入实战；试玩退出后回到工坊。
10. 完成后点击“保存”。保存成功后，主菜单的“自定义关卡”会显示该关卡，之后可重复游玩。

所有编辑会自动保存。主动点击“保存”并命名后，关卡会写入：

```text
user://level_drafts/<关卡编号>.json
```

右侧角色只是静态展示，不会移动、攻击或进入正式战斗；点击“试玩”后才进入正式战斗场景。保存的 JSON 会动态转换为 `ResourceLevelData`，并出现在“自定义关卡”列表中，不会修改项目内置关卡资源。

## 给开发者

实体目录可通过以下代码取得：

```gdscript
LevelDraftStore.global_draft_directory()
```

运行流程：

1. 从草稿目录取得 JSON。
2. 用 `LevelJsonRuntime.load_level(path)` 校验并读取。
3. `waves[*].stageType` 使用 `flag` 或 `interval` 区分旗帜波和波间阶段；旧 JSON 会自动把原有波次迁移为旗帜波，并把原有时间空档转换为波间阶段。
4. 用 `LevelJsonRuntime.build_spawn_schedule(level)` 生成确定性的逐只刷怪时间表，其中包含绝对时间、僵尸类型和路线。
5. `LevelCustomRuntime.build_game_para(level)` 将时间表、旗帜时间点和关卡总时长转换为运行时 `ResourceLevelData`；主游戏按帧推进时间表并同步右下角旗帜进度条。

现有正式关卡仍由 `resources/level_date_resource/` 和 `level_game_para/` 管理。工坊不会自动修改这些目录；玩家保存的 JSON 由“自定义关卡”界面动态加载。

## 主菜单入口调节

关卡工坊入口使用竖向石牌贴图和项目现有的方正少儿字体。打开 `scenes/main/01StartMenu.tscn`，选中根节点 `StartMenu`，在 Inspector 的“关卡工坊入口 Transform”分组中可调节：

- `level_workshop_button_position`
- `level_workshop_button_rotation_degrees`
- `level_workshop_button_scale`

按钮节点本体路径为 `BG_Right/Menu/LevelWorkshopButton`，也可以直接在该节点的 Transform 中查看最终尺寸和锚点。
