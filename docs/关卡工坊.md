# 游戏内关卡工坊

## 给普通玩家

从主菜单点击“关卡工坊”后，会直接进入白天草坪编排场景：

1. 左侧是项目现有僵尸卡片。点击一次卡片，当前波次中该僵尸数量加一。
2. 所有已选择的僵尸会用真实角色场景显示在右侧大马路上。
3. “已选择”列表可以增减数量；点击僵尸名称可以调整路线和生成间隔。
4. 点击“新建下一波”时，当前波自动保存，右侧道路清空，然后开始选择下一波僵尸。
5. 返回以前的波次时，会重新显示该波已经保存的僵尸。
6. 完成后点击“保存全部草稿”。

所有编辑会自动保存。主动点击“保存草稿”后，关卡会写入：

```text
user://level_drafts/<关卡编号>.json
```

右侧角色只是 `IsShow` 展示状态，不会移动、攻击或进入正式战斗。工坊保存的是“待审核草稿”，不会自动出现在正式选关或自定义关卡列表中。

## 给开发者

实体目录可通过以下代码取得：

```gdscript
LevelDraftStore.global_draft_directory()
```

审核流程：

1. 从草稿目录取得 JSON。
2. 用 `LevelJsonRuntime.load_level(path)` 校验并读取。
3. 用 `LevelJsonRuntime.build_spawn_schedule(level)` 检查确定性刷怪时间表。
4. 确认角色 ID、路线规则和难度符合当前模式后，再决定是否编写对应模式适配器，或转换成项目现有的 `ResourceLevelData` `.tres` 资源。

现有正式关卡仍由 `resources/level_date_resource/` 和 `level_game_para/` 管理。工坊不会自动修改这些目录，也不会自动注册正式关卡。
