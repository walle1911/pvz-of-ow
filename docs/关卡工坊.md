# 游戏内关卡工坊

## 给普通玩家

从开发者模式点击“关卡工坊”后会直接进入普通关卡编辑器，不再显示模式选择或冒险选关页。僵尸图鉴面板会从左侧滑入，占据屏幕约 47%，背景与视口右边缘对齐，右侧保留完整马路用于查看当前阶段已经选择的僵尸：

1. 工坊每次打开默认进入“简易模式”。简易模式直接使用 PvZ1 原版关卡框架：设计数据只有总波数与本关允许僵尸表；开战前按每波点数、固定权重、最早允许波次和原版旗帜判定预生成全部小波名单，再交给正式波次管理器推进。它不会把一个“波间”复制成十波，也不会生成进阶模式的逐只定时事件。
2. 右上角“进阶模式”位于“试玩”左侧，外观和尺寸与相邻按钮一致。进入进阶模式后恢复原有的逐阶段精确数量编辑；按钮会变为“简易模式”，可随时切回。
3. 简易模式中，左侧点击卡片只会把该种僵尸加入整关唯一的允许僵尸表，已选卡片显示为暗色；右侧马路每种允许僵尸只展示一个代表。点击道路上的具体僵尸只能查看原版抽取说明或将其从允许表删除。简易模式没有“必须登场”和逐种数量接口。
4. 简易“设置”只保留关卡名称、草稿编号、五种原版地图、总波数、开局阳光、自由选卡和通关奖励植物。植物池仍在“可选卡片”页面编辑，只有已选植物显示为暗色；再次点击已选植物可以设置“必须携带”，右下角可清空所有可移除卡片。植物选择页会隐藏旗帜进度条及其时间轴操作。
5. “地图特殊设定”跟随地图显示：夜晚草坪可以启用墓碑并设置初始墓碑数量，屋顶可以启用蹦极大波，其他地图显示为没有需要手动启用的特殊机制。墓碑位置和蹦极目标均由运行时决定。
6. 简易模式不存在“非旗帜波池”和“旗帜波池”，也不开放插旗、删旗或重置时间轴。旗帜波按原版规则由总波数和当前波号自动推导；总波数少于 10 时以整关波数作为每旗波数，否则每 10 波判定一次旗帜波。右下角时间轴仅展示推导结果，不能选择或修改具体小波。

以下为进阶模式及通用操作：

1. 左侧面板直接使用 `Almanac_ZombieBack.jpg`，按钮、弹窗和进度条只复用 `assets/image/Almanac/` 与 `assets/image/ui/` 中的现有素材；工坊全部文字统一使用 `方正少儿_GBK.ttf`。
2. 右下角进度条复用正式关卡的旗帜进度条素材，保持原始比例并仅做整体等比缩放。旗帜头部与进度槽下半部使用独立命中带：点击旗帜头部选择旗帜，点击槽体下半部选择波间，因此短波间也不会被相邻旗帜遮挡。波间不再设置固定持续时间，而是复用正式关卡的动态推进参数；插旗会拆分目标波间，“重置”会恢复为两个动态波间和两面旗帜。
3. 旗帜波会在试玩时触发“一大波僵尸来袭”，并升起右下角进度条中的对应旗帜；波间阶段也可以正常配置和刷新僵尸。
4. 左侧直接读取 `AllCards.all_zombie_card_prefabs` 中的全部僵尸，并保持游戏现有卡牌外观。卡片采用每页 24 张、6 列×4 行的图鉴式分页，不会为了塞满一页而挤在一起。
5. 每次点击卡片都会打开石碑弹窗，用数值选择器直接设置该僵尸在当前阶段的出场数量；设置为 0 可以从当前阶段移除。
6. 右侧大马路沿用正式关卡开局展示逻辑，实例化正常大小的 `IsShow` 僵尸并在道路区域随机排布。删除采用角色贴图逐像素透明度命中，只有点击具体可见的僵尸像素才会从当前阶段删除一只同类型僵尸；透明空白、矩形包围区和影子不会触发删除。预览最多显示 20 只，超过部分会显示数量提示；实际出生数量和路线不受预览上限影响。
7. 试玩时按本阶段相对时间逐只生成僵尸并随机分排；全部配置僵尸出场后，普通阶段至少等待 6 秒，并在剩余有效血量降至初始总有效血量的 50%～67% 时提前推进，否则在 25～31 秒自然推进。旗帜前阶段需要清空本阶段僵尸才能提前推进，否则在 40～46 秒自然推进。
8. 切换进度条阶段时会恢复该阶段的预览。
9. 点击“试玩”，会直接使用当前自动保存的内容进入实战；试玩退出后回到工坊。
   试玩局右上角菜单键左侧会显示同样式的“编辑”键，可随时直接回到刚才的工坊编辑界面。
10. 底部新增“新建关卡”。新建内容完成后点击“保存”会弹出命名窗口，并直接写入“开始冒险吧”的“自制关卡”。
11. 点击“载入关卡”会先显示“关卡模板”和“自制关卡”两个入口；前者可载入普通线 50 个预设，后者可继续编辑玩家已经保存的关卡。
12. 从关卡模板或自制关卡载入并修改后，点击“保存”会选择“覆盖原有关卡”或“保存至自制关卡”。选择后者会再弹出命名窗口，并生成独立的新关卡。
13. 覆盖关卡模板会把当前配置写入项目内 `data/adventure_levels/<关卡 ID>.json`；这份覆盖只供开发者模式“开始冒险吧”使用，普通模式正式冒险始终读取内置预设。
14. “关卡设置”可修改正式关卡名称，并从已注册植物卡中选择本关通关后掉落的一张新卡（也可设为无掉落）。正式通关时会记录该奖励并加入玩家卡池。

所有编辑会自动保存。主动点击“保存”并命名后，关卡会写入：

```text
user://level_drafts/<关卡编号>.json
```

右侧角色只是静态展示，不会移动、攻击或进入正式战斗；点击“试玩”后才进入正式战斗场景。保存的 JSON 会动态转换为 `ResourceLevelData`，并出现在“自定义关卡”列表中，不会修改项目内置关卡资源。

## 给开发者

实体目录可通过以下代码取得：

```gdscript
LevelDraftStore.global_draft_directory()
```

## 工坊模式

工坊当前只开放普通关卡编辑模式。简易模式不显示天降阳光速度、卡片冷却、随机种子和精确出怪节奏；这些参数只保留在进阶模式。棋盘格玩法本身仍可在正式游戏中使用，但工坊不再提供棋盘格编辑入口。

“设置”使用项目已有的 `option_dialog.png`、`btn_dialog_back_2.png`、图鉴关闭按钮和方正少儿字体组合，不使用 Godot 默认弹窗皮肤。

运行流程：

1. 从草稿目录取得 JSON。
2. 用 `LevelJsonRuntime.load_level(path)` 校验并读取。
3. `waves[*].stageType` 使用 `flag` 或 `interval` 区分旗帜波和波间阶段；旧 JSON 会自动把原有波次迁移为旗帜波，并把原有时间空档转换为波间阶段。
4. 进阶模式用 `LevelJsonRuntime.build_spawn_schedule(level)` 生成确定性的逐只刷怪时间表，其中包含绝对时间、僵尸类型和路线；简易模式不会使用这张时间表。
5. `LevelCustomRuntime.build_game_para(level)` 在简易模式中按 PvZ1 `PickZombieWaves` 规则预生成每个小波的僵尸名单；进阶模式才把各阶段相对刷怪计划和旗帜位置转换为运行时数据。主游戏随后使用对应的正式波次推进规则并同步右下角进度条。

新建关卡会命名后保存为自制关卡；载入已有内容后，保存时可以选择覆盖来源或另存为新的自制关卡。覆盖关卡模板只会写入开发者模式专用的覆盖数据。

## 成品主线关卡

“开始冒险吧”保留两条平行主线：普通模式与棋盘格模式。普通模式现有白天、夜晚、泳池、雾夜、屋顶五个世界，每个世界 10 关，共 50 个成品关卡；棋盘格模式继续保留白天 10 关。主线选关页不再混入保龄球、锤僵尸、种子雨等小游戏，原有小游戏继续集中在“小游戏”列表。

成品默认设计定义在：

```text
scripts/resources/level/adventure_level_presets.gd
```

工坊“应用预设”生成的开发者覆盖数据位于：

```text
data/adventure_levels/<关卡 ID>.json
```

普通模式正式选关始终读取 `adventure_level_presets.gd` 的默认生成规则，不读取覆盖 JSON。开发者模式“开始冒险吧”先列出同样的 50 个正式预设，并优先读取这里的覆盖 JSON；玩家保存的自定义关卡排在全部预设之后。

普通线按实战用途重新安排卡片：1-1 直接提供基础攻击与经济卡，之后多数关卡都会增加一张新卡，夜晚和泳池开场会一次补足对应战术卡；31 张已有正式卡片会在 4-9 前全部开放。未改版原版植物不会进入普通主线，只有墓碑吞噬者、睡莲、花盆三张地形工具卡例外，并且只在需要它们的地图出现。棋盘格线继续只提供原版植物。

普通线的新僵尸按难度逐步加入：白天先引入 Talon 基础、路障、豌豆射手和铁桶僵尸；夜晚加入卢西奥舞王、死神惊喜盒、探奇矿工和温斯顿雪人；泳池加入水路僵尸与诗音冰车；雾夜开始出现气球、弹跳、梯子和莱因哈特巨人；屋顶再加入投石车、鲍勃巨人和橄榄球冲锋。当前没有改版替代的水路与地图机制僵尸会保留原版实现，否则泳池、雾夜和屋顶机制无法完整运作。

夜晚从 2-2 起生成墓碑并开放墓碑吞噬者；泳池与雾夜使用六路地图，水生僵尸只会走中间两条水路，陆地僵尸不会错误刷进水里；屋顶从 5-3 起启用蹦极大波。最终大波还会复用泳池珊瑚僵尸等地图原生机制。

每个世界的十关波数依次为 5、6、7、8、10、10、12、12、15、20。全局关卡序号会同时提高每波点数预算、后期敌人占比和同屏上限；世界内小关逐步加压，10 关作为该地图的多旗帜决战。后期自然刷新间隔会从约 29–34 秒逐渐缩短到约 22–27 秒，但仍保留最低战斗时间和剩余血量提前刷新，避免只靠拖时长制造难度。

工坊“成品关卡”默认载入内置预设；若该关已应用过开发者覆盖，则继续载入覆盖版本。点击“应用预设”只更新开发者模式中的对应预设，不会改动普通冒险。

## 主菜单入口调节

关卡工坊入口使用竖向石牌贴图和项目现有的方正少儿字体。打开 `scenes/main/01StartMenu.tscn`，选中根节点 `StartMenu`，在 Inspector 的“关卡工坊入口 Transform”分组中可调节：

- `level_workshop_button_position`
- `level_workshop_button_rotation_degrees`
- `level_workshop_button_scale`

按钮节点本体路径为 `BG_Right/Menu/LevelWorkshopButton`，也可以直接在该节点的 Transform 中查看最终尺寸和锚点。
