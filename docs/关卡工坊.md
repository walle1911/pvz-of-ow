# 游戏内关卡工坊

## 给普通玩家

从主菜单点击“关卡工坊”后，会直接进入白天草坪编排场景：

1. 下方进度条把关卡分成两类阶段：`🚩 旗帜波` 和旗帜之间的 `波间间隔`。点击对应节点即可切换编辑对象。
2. 旗帜波会在试玩时触发“一大波僵尸来袭”，并升起右下角进度条中的对应旗帜；波间间隔也可以正常配置和刷新僵尸。
3. 左侧直接读取 `AllCards.all_zombie_card_prefabs` 中的全部僵尸，并保持游戏现有卡牌外观。点击一次卡片，当前选中阶段中该僵尸数量加一。
4. 每种僵尸只需设置数量、进入该阶段后的首次出现时间和逐只生成间隔；出生行由试玩时的随机路线规则决定，不在工坊中固定。
5. 右侧大马路使用 `AllCards` 的静态角色图展示种类和数量，不运行完整僵尸脚本，不对齐具体草坪行，也不显示角色阴影。预览最多显示 20 只，超过部分会显示数量提示；实际出生数量和路线不受预览上限影响。
6. 试玩时不会在阶段开始时一次生成全部僵尸，而是按照绝对时间表逐只生成并随机分排。
7. 点击“新增旗帜”会同时在末尾新增一个波间阶段和下一次旗帜波；选中阶段后可点击“删除当前”，至少保留一个旗帜波，误删可撤销。
8. 切换进度条阶段时会恢复该阶段的预览。
9. 点击“立即试玩”，会直接使用当前自动保存的内容进入实战；试玩退出后回到工坊。
10. 完成后点击“保存并命名”。保存成功后，主菜单的“自定义关卡”会显示该关卡，之后可重复游玩。

所有编辑会自动保存。主动点击“保存并命名”后，关卡会写入：

```text
user://level_drafts/<关卡编号>.json
```

右侧角色只是 `IsShow` 展示状态，不会移动、攻击或进入正式战斗；点击“立即试玩”后才进入正式战斗场景。保存的 JSON 会动态转换为 `ResourceLevelData`，并出现在“自定义关卡”列表中，不会修改项目内置关卡资源。

## 给开发者

实体目录可通过以下代码取得：

```gdscript
LevelDraftStore.global_draft_directory()
```

运行流程：

1. 从草稿目录取得 JSON。
2. 用 `LevelJsonRuntime.load_level(path)` 校验并读取。
3. `waves[*].stageType` 使用 `flag` 或 `interval` 区分旗帜波和波间阶段；旧 JSON 会自动把原有波次迁移为旗帜波，并把原有时间空档转换为波间阶段。
4. 用 `LevelJsonRuntime.build_spawn_schedule(level)` 生成确定性的逐只刷怪时间表，其中包含绝对时间、僵尸类型和路线。
5. `LevelCustomRuntime.build_game_para(level)` 将时间表、旗帜时间点和关卡总时长转换为运行时 `ResourceLevelData`；主游戏按帧推进时间表并同步右下角旗帜进度条。

现有正式关卡仍由 `resources/level_date_resource/` 和 `level_game_para/` 管理。工坊不会自动修改这些目录；玩家保存的 JSON 由“自定义关卡”界面动态加载。

## 主菜单入口调节

关卡工坊入口使用竖向石牌贴图和项目现有的方正少儿字体。打开 `scenes/main/01StartMenu.tscn`，选中根节点 `StartMenu`，在 Inspector 的“关卡工坊入口 Transform”分组中可调节：

- `level_workshop_button_position`
- `level_workshop_button_rotation_degrees`
- `level_workshop_button_scale`

按钮节点本体路径为 `BG_Right/Menu/LevelWorkshopButton`，也可以直接在该节点的 Transform 中查看最终尺寸和锚点。
