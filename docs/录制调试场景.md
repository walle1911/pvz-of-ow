# 录制调试场景

入口场景：`res://scenes/main/test/MainGameDebugRecording5757.tscn`
夜晚入口场景：`res://scenes/main/test/MainGameDebugRecording5757Night.tscn`

夜晚入口除使用前院夜晚地图、夜晚 BGM 与夜晚植物状态外，其余功能与 5757 导演场景相同；但不响应 `Z` 与 `X` 的天使向日葵/巴蒂斯特火炬快捷补种。

这个场景用于录制角色行为，固定具备以下条件：

- 阳光永久锁定为 `5757`，种植、收集阳光或其他系统修改都不会改变该数值；
- 关闭天降阳光；
- 僵尸刷新模式为 `Null`，不会自动开始波次；
- 进入场景后正常展示僵尸并进入植物/僵尸选卡界面；
- 右上角显示“录制调试台”。

## 使用方法

1. 在 Godot 中直接运行入口场景，等待 Ready/Set/Plant 结束。
2. 按 `P` 或点击“冻结全部五行”，冻结当前全部植物和僵尸。
3. 在冻结期间：
   - 直接点击原卡槽中的植物卡，再点击草坪格种植；
   - 直接点击原铲子，再点击草坪上的植物铲除；
   - 选择僵尸、行和列，点击“放置僵尸”；
   - 从“场上角色”列表选择已有角色后，可直接删除；
   - 选择角色事件并加入解冻事件队列。
4. 再按 `P` 或点击“全部解冻并执行队列”。冻结期间种下的植物和放置的僵尸会继续留在场上并开始运行；排队事件在解冻后 `1.5` 秒触发。

`F2` 可以随时完整隐藏或重新显示录制调试台，不改变当前行冻结状态。

`S` 会把当前植物与僵尸布置保存为一条持久化布景快照。快照记录植物格子、类型和血量，以及僵尸类型、行、精确坐标和血量。按 `F2` 打开导演台后，可从“布景快照”列表恢复或删除所选记录。恢复时会替换当前场上角色、关闭 F6，并让新布景保持五行冻结和灰色标记，确认无误后再按 `P` 开拍。

F2 导演台的“选择场上角色”区域提供本体当前血量输入框和“设置所选目标血量”按钮。选择任意植物或僵尸后，输入值会自动显示当前血量与该角色的最大血量；设置时仅修改本体当前血量，不改变护甲或血量上限。

`F4` 可以显示或收起全部僵尸导演卡。这里的僵尸卡为零消耗、无冷却，可直接选卡后点击草坪反复放置，不会改变初始阳光 `5757`。

`Q`、`W`、`E`、`R`、`T` 分别切换第 1～5 行的时间冻结。冻结后该行已有及新放置的植物、僵尸都会停止行动，再按一次对应按键即可解冻该行。

被冻结的植物和僵尸会临时显示为低饱和灰色，作为拍摄和剪辑的明确分界标记；解冻后自动恢复各自原有材质和颜色。

`P` 全权管理五行总冻结：第一次按下时关闭 F6 持续齐射、恢复正常敌人检测并冻结全部五行；再次按下时全部解冻。各行仍可随时通过 `Q/W/E/R/T` 独立切换冻结状态。

`Shift+P+Q/W/E/R/T` 用于“只让一行运行”。例如按住 `Shift+P` 后按 `E`，会明确设置为仅第 3 行运行、其余四行全部冻结；`Q/W/R/T` 分别对应只保留第 1/2/4/5 行。按住 `Shift` 时的 `P` 不会提前触发普通全冻切换。

`L` 会无条件解除全部五行的冻结，包括 P 全冻、Q/W/E/R/T 单行冻结和 `Shift+P+行键` 组合状态，对应的植物子弹也会继续飞行。`L` 仅清除冻结，不会提前触发原本等待 P 全部解冻的导演事件队列。

冻结某一行时，该行植物已经发出、仍在飞行的子弹也会同步停住；解冻该行后子弹从原位置继续飞行。僵尸阵营的子弹不受此条植物子弹规则影响。

植物和僵尸的冻结归属不会在跨行瞬间改变。角色离开原行后仍按原行的冻结状态运行；只有在新行连续停留满 4 秒，才正式归属新行并跟随新行的冻结状态。中途返回原行或改去另一行时，4 秒计时会重新开始。

`F6` 会开启天使蓝线白名单中全部射手类植物的持续强制开火，并按照各自原本的攻击间隔反复触发；再按一次 `F6` 即可关闭。强制开火不需要检测到僵尸：投手类若没有实际目标，会朝本行前方的虚拟落点投掷，因此艾什版西瓜投手也会完整播放射击并抛出西瓜。

`O` 会从草坪右侧启动一次黑爪导演波次。每行各生成 1 只黑爪普通、1 只黑爪路障、1 只黑爪旗帜和 1 只黑爪铁桶僵尸，共 20 只。僵尸以约 0.3～0.65 秒的错峰间隔按波次节奏生成，不会同时出现；本波生成完成前不会重叠启动第二波。

`Z` 会遍历 F6/天使蓝线共用白名单中的射手，尝试在每株射手后方（左侧）一格种下天使版向日葵。`X` 会尝试在每株射手前方（右侧）一格种下巴蒂斯特版火炬树桩。目标格越界、已有同层植物或不满足地形条件时会自动跳过，不会覆盖现有布置。

解冻事件只支持 Bob、莱因哈特巨人和死神小丑，包括本次冻结期间刚放置的角色：Bob、莱因哈特在解冻后 `1.5` 秒投掷小鬼，死神小丑在解冻后 `1.5` 秒直接爆炸。

本工具不再使用 `SceneTree.paused`；P 与 Q/W/E/R/T 只冻结对应行的角色时间，因此卡槽、铲子和导演 UI 始终可操作。
