# 高级录制导演场景

## 场景入口

- 白天前院：`res://scenes/main/test/MainGameDebugRecording5757.tscn`
- 夜晚前院：`res://scenes/main/test/MainGameDebugRecording5757Night.tscn`
- 泳池：`res://scenes/main/test/MainGameDebugRecording5757Pool.tscn`

直接在 Godot 中运行对应场景。`F2` 唤出导演台，`P` 暂停/恢复全部角色；进入 A 群像幕后按 `O` 正式开始。

如果 Godot 开启了 Embed Game，导演场景会自动重新启动为独立游戏窗口，因为原生导演台不能可靠地附着在编辑器内嵌视口中。独立窗口出现后，`F2` 可随时重新显示并聚焦导演台。

## 纯静止编辑模式

编辑模式下所有植物和僵尸都完全静止，不会攻击、移动、受击或互相检测。

1. 按 `Q / W / E / R / T / Y / U / I` 选择第 1～8 幕。
2. 选择一幕后，新种下的植物和新放置的僵尸自动归入当前幕。
3. 当前幕植物保持正常显示；其他幕植物保留在场上，但显示为低饱和、`32%` 不透明度的背景。
4. 当前幕专属僵尸可见但静止；其他幕专属僵尸完全隐藏。
5. A/Q～I 切幕本身永不保存。切换时会丢弃当前运行现场，并从最后一次明确保存的整体快照重建目标幕；再次切回时仍是该幕最后保存时的初始状态。
6. 导演台可以按行、列放置当前幕专属僵尸，并设置角色本体血量或删除角色。
7. 每次点击“保存整体快照”都会新增一个带保存时间的历史版本，保存八幕全部植物、僵尸、位置、血量和幕归属。先在“整体快照历史”下拉框选择时间，再点“恢复整体快照”重建完整编排，或点“恢复当前幕”只重建所选幕并强制暂停。
8. 每次重新启动录制场景都从零开始，不自动加载上次现场；历史快照文件仍然保留，只会在用户明确选择并恢复后载入。
9. 仅在录制导演场景中，顶部已选卡预选框分为植物页和僵尸页，只能按 `Shift` 来回切换；选卡阶段切到僵尸页后，可把僵尸卡加入独立的顶部预选框。进入纯静止编辑后仍可按 `Shift` 显示僵尸卡，选中后点击草坪即可把僵尸自由安放到当前幕。普通正式关卡不启用这套双页预选框。
10. 游戏开始后，`Z / X` 分别会在现有射手的后方、前方一键补种天使向日葵和巴蒂斯特火炬；`C` 会在草坪右数第三列逐行批量种下拉玛刹菜问。新植物自动归入当前幕。
11. 导演台提供“清空这一幕（植物＋僵尸）”和“清空这一幕所有僵尸（保留植物）”两个按钮，只处理当前 Q～I 幕，不影响其他幕；清空后仍需点击“保存整体快照”才会新增持久化历史版本。
12. 切换到 Q～I 任一幕时，“当前幕指定植物 / 僵尸血量”列表只显示该幕角色，并标明所在行列；选择目标、输入本体当前血量后即可单独设置，不会改变最大血量、护甲或其他幕角色。

A 不存在编辑幕。群像总览由八幕植物自动合成，不需要单独编辑。
总幕中的每一株植物也都来自它所属分幕最后保存时的初始状态；任何分幕运行后的位移、掉血、死亡和技能状态都不会进入总幕。

## 正式运行模式

在 A 群像幕按 `O` 才会正式开始。控制器会先把当前八幕编排持久化为整体母版，然后从母版重建群像，先在草坪右侧每行只生成 1 只先锋，此后每 0.4 秒只向下一行补充 1 只，逐行循环输送。按 `P` 暂停或切换到 Q～I 分镜时停止刷新；回到 A 幕且未暂停时自动继续。无论按 O 前后，每次按 A 或 Q～I 切换，都会先丢弃上一幕的运行现场，再从整体母版重建角色，因此掉血、死亡、移动和技能状态不会串幕。重建期间会保持切换前的最后一帧，完成后直接热切到新幕，不再使用黑屏淡入淡出。

### A：群像总览

- 八幕植物全部恢复正常并共同战斗。
- 八幕专属僵尸全部隐藏。
- 卡牌、草坪和铲子保持正常可操作，可以继续种植或铲除植物。
- 按 O 时从草坪右侧每行只生成 1 只先锋，然后每 0.4 秒只向下一行补充 1 只，按行循环。白天对应第 1 世界、夜晚对应第 2 世界、泳池对应第 3 世界，雾与屋顶依次对应第 4、5 世界。僵尸种类从该世界十关正式冒险配置实时汇总，包含其中的 OW 替换角色和终局限定角色；世界级 OW 追加角色会强制合并。索杰恩在导演尸群中整场只生成 1 只，不进入后续循环输送。
- 切到 Q～I 后，这同一批右侧尸群不会被删除，会被冻结、关闭碰撞并半透明显示；最后按 A 时恢复正常显示和运行，不会重复生成另一批。
- 泳池地图还会按陆地行/泳池行过滤可用类型；Boss 不进入尸群。

### Q～I：单幕特写

- 只有当前幕植物和当前幕专属僵尸运行并互相作用。
- 其他幕植物完全静止、无碰撞、无索敌，并显示为半透明背景。
- 其他幕专属僵尸完全隐藏。
- A 群像尸群被冻结并作为半透明背景保留，不参与当前分幕战斗。
- 切换幕时会立即清空飞行中的子弹；当前幕结束后产生的爆炸物、阳光、掉血、死亡和状态变化不会进入其他幕。

推荐录制顺序：`A → Q → W → E → R → T → Y → U → I → A`。

## 已移除的旧导演功能

旧版的 F4 僵尸卡墙、F6 强制齐射、组长/组员操作、最多两组运行队列、通用僵尸组、解冻事件队列、普通布景快照和九幕独立快照均已移除。P 现用于全体暂停/恢复，O 现用于在 A 群像幕保存整体母版并正式开始。Z/X 快捷补种已保留，并新增 C 拉玛刹菜问补种与 Shift 僵尸预选页。
