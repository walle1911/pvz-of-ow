# 录制调试场景

入口场景：`res://scenes/main/test/MainGameDebugRecording5757.tscn`

这个场景用于录制角色行为，固定具备以下条件：

- 初始阳光为 `5757`；
- 关闭天降阳光；
- 僵尸刷新模式为 `Null`，不会自动开始波次；
- 进入场景后正常展示僵尸并进入植物/僵尸选卡界面；
- 右上角显示“录制调试台”。

## 使用方法

1. 在 Godot 中直接运行入口场景，等待 Ready/Set/Plant 结束。
2. 按 `F3` 或点击“进入录制暂停”。这是游戏内的录制暂停，不是编辑器断点暂停。
3. 在暂停期间：
   - 选择植物、行和列，点击“放置植物”；
   - 选择僵尸、行和列，点击“放置僵尸”；
   - 从“场上角色”列表选择已有角色后，可直接删除；
   - 选择角色事件并加入恢复事件队列。
4. 再按 `F3` 或点击“恢复并执行队列”。暂停期间放置的植物和僵尸会继续留在场上并开始运行；排队事件在恢复后 `1.5` 秒触发。

`F2` 可以随时完整隐藏或重新显示录制调试台，不改变当前暂停状态。

恢复事件只支持 Bob、莱因哈特巨人和死神小丑，包括本次暂停期间刚放置的角色：Bob、莱因哈特在恢复后 `1.5` 秒投掷小鬼，死神小丑在恢复后 `1.5` 秒直接爆炸。

> IDE 的断点暂停会冻结游戏线程，无法让调试 UI 在暂停期间可靠工作，因此本工具使用 `SceneTree.paused` 实现录制暂停。
