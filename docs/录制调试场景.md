# 录制调试场景

入口场景：`res://scenes/main/test/MainGameDebugRecording5757.tscn`
夜晚入口场景：`res://scenes/main/test/MainGameDebugRecording5757Night.tscn`

夜晚入口除使用前院夜晚地图、夜晚 BGM 与夜晚植物状态外，其余功能与 5757 导演场景相同；但不响应 `Z` 与 `X` 的天使向日葵/巴蒂斯特火炬快捷补种。

这个场景用于录制角色行为，固定具备以下条件：

- 阳光永久锁定为 `5757`，种植、收集阳光或其他系统修改都不会改变该数值；
- 关闭天降阳光；
- 僵尸刷新模式为 `Null`，不会自动开始波次；
- 进入场景后正常展示僵尸并进入植物/僵尸选卡界面；
- 右上角显示“录制调试台”。

## 使用方法

1. 在 Godot 中直接运行入口场景，等待 Ready/Set/Plant 结束。
2. 在“当前角色”区域用下拉框或鼠标点击选中场上角色；然后在“冻结编组”区域选择第 1～5 组，把当前植物设为组长，或把当前角色加入该组。每组必须先有植物组长，同一角色只能属于一组。
3. 按 `P` 或点击“冻结全部编组”，冻结第 1～5 组并重置运行队列；未编组角色保持运行。
4. 在冻结期间：
   - 直接点击原卡槽中的植物卡，再点击草坪格种植；
   - 直接点击原铲子，再点击草坪上的植物铲除；
   - 选择僵尸、行和列，点击“放置僵尸”；
   - 从“场上角色”列表选择已有角色后，可直接删除；
   - 选择角色事件并加入解冻事件队列。
5. 按 `O` 放行剩余全部编组，同时从右侧启动黑爪波次。冻结期间种下的植物和放置的僵尸会继续留在场上；排队事件在解冻后 `1.5` 秒触发。

在 Godot 4.6 编辑器中点击“运行当前场景”时，如果项目被配置为嵌入编辑器运行，导演场景会自动重新启动为独立项目窗口，并关闭原先的嵌入实例。macOS 程序坞中会显示项目的 PVZ 图标，独立导演台也会随之弹出；从命令行或独立窗口启动时不会重复拉起进程。

新种植的植物默认未编组，因此不会被冻结。通过导演台“放置僵尸”按钮、F4 导演卡或普通僵尸卡手动放入的僵尸，会在创建时自动加入导演台当前选择的第 1～5 组，并立即继承该组的冻结状态；其中导演台按钮和 F4 导演卡创建的僵尸会按 Inspector 中的 `director_placed_zombie_scale` 等比缩放，默认是原体积的 `80%`。该组尚未指定植物组长时，僵尸仍会正常创建，但保持未编组。关卡波次、O 波次和角色召唤出来的僵尸不会自动入组，也不会应用导演放置缩放。

“当前角色”是删除、调整血量、编组和解冻事件共用的唯一选择。原有三种鼠标能力没有删除，而是合并到同一行的点选用途：可选“选为当前角色”“直接设为所选组组长”或“连续加入所选组”，再点击“开始场上点选”或按 `M`。连续加入模式按右键或 `Esc` 结束。角色选择或编组成功时会播放一次确认音效；点空、不合法目标和取消操作不会播放。点选期间的草坪点击会被导演台接管，不会误种植或误铲除。

录制调试台使用独立的原生悬浮窗口，并在进入导演场景时自动弹出，不再覆盖主游戏视口。窗口带系统标题栏，可以自由拖动、缩放、移到游戏窗口外或第二块屏幕；导演场景运行期间窗口保持显示。`F2` 只用于把导演台重新唤出并聚焦，不会隐藏窗口。

`S` 会把当前植物与僵尸布置保存为一条持久化布景快照。快照记录植物格子、类型和血量，僵尸类型、行、精确坐标和血量，以及五组的组长、组员归属和保存时的冻结状态。可从导演悬浮窗的“布景快照”列表恢复、重命名或删除所选记录；重命名后会立即写入共享快照库，删除任何快照前都会弹出带当前名称的二次确认。恢复会替换当前场上角色、关闭 F6，并在新角色实例上重新建立原有编组。旧版本中没有编组字段的快照仍可恢复，角色会保持未编组。

导演台的“当前角色”区域也可使用下拉列表选择目标。当前角色可直接用于删除、调整本体当前血量、编组或设置解冻事件；血量输入值会自动显示当前血量与该角色的最大血量，设置时不改变护甲或血量上限。

`F4` 可以显示或收起全部僵尸导演卡。这里的僵尸卡为零消耗、无冷却，可直接选卡后点击草坪反复放置，不会改变初始阳光 `5757`。每次点击草坪创建僵尸时读取导演台当前选中的组并自动入组，同时按 Inspector 配置缩放为默认 `80%`，因此切换组后无需重新选择僵尸卡。

`Q`、`W`、`E`、`R`、`T` 分别切换第 1～5 组的时间冻结。冻结后该组的植物和僵尸都会停止行动，再按一次对应按键即可解冻该组；角色跨行移动不会改变所属组。

按下 `O` 之前，运行队列最多容纳两个已解冻组，并按解冻顺序先进先出。例如依次解冻 Q、W、E 时，E 入队并让最早的 Q 自动冻结；随后解冻 R 时，W 自动冻结。手动冻结某个运行组会将它移出队列。`P` 会冻结全部组并清空队列，重新开始这一轮限制。

在导演台中切换“第 1～5 组”时，编组摘要下方会显示当前组选中的组长，以及每个植物或僵尸组员的名称和所在行列。

编组本身不限制索敌。只要攻击者和目标都没有被冻结，无论双方是否编组、是否属于同一组，都会完全沿用原游戏的索敌和攻击规则。被冻结角色在逻辑上视为不存在，其他正在运行的植物或僵尸检测不到它。

被冻结的植物和僵尸会临时显示为低饱和灰色，作为拍摄和剪辑的明确分界标记；解冻后自动恢复各自原有材质和颜色。

冻结角色在画面中仍然可见，但其全部物理碰撞区会临时关闭，相当于场景中没有实体。其他仍在运行的组所发射的子弹不会命中冻结角色，而会直接穿过；解冻时会精确恢复角色冻结前各碰撞区的层、遮罩和检测状态。

`P` 会关闭 F6 持续齐射、冻结五个编组及其在途子弹，并清空运行队列；未编组角色和无法归属编组的子弹始终保持运行。P 始终只负责全体编组暂停，全部放行与右侧刷怪统一使用 `O`。

`Shift+P+Q/W/E/R/T` 用于“只让一组运行”。例如按住 `Shift+P` 后按 `E`，会明确设置为仅第 3 组运行、其余四组全部冻结；`Q/W/R/T` 分别对应只保留第 1/2/4/5 组。按住 `Shift` 时的 `P` 不会提前触发普通全冻切换。

`O` 会无条件解除五个编组的冻结，包括 P 全冻、Q/W/E/R/T 单组冻结和 `Shift+P+组键` 组合状态，关闭本轮“两组运行”限制，对应的编组子弹也会继续飞行，并立即刷新全部植物和僵尸的索敌。组长和组员关系仍会保留，但此时不再有冻结组别限定；原本排队的导演事件会在 O 放行后 `1.5` 秒触发。再次按 `P` 会重新启用两组限制。

冻结某一组时，该组植物或僵尸已经发出、仍在飞行的子弹也会同步停住；解冻该组后，双方子弹都会从原位置继续飞行。无法确认发射者或没有编组的子弹不会被冻结。

`F6` 会开启天使蓝线白名单中全部射手类植物的持续强制开火，并按照各自原本的攻击间隔反复触发；再按一次 `F6` 即可关闭。强制开火不需要检测到僵尸：投手类若没有实际目标，会朝本行前方的虚拟落点投掷，因此艾什版西瓜投手也会完整播放射击并抛出西瓜。

`O` 在完成全部放行后，会从草坪右侧启动一次黑爪导演波次。每行各生成 1 只黑爪普通、1 只黑爪路障、1 只黑爪旗帜和 1 只黑爪铁桶僵尸，共 20 只。这些波次僵尸保持各自原始体积，不应用导演放置的 `80%` 缩放。僵尸以约 0.3～0.65 秒的错峰间隔按波次节奏生成，不会同时出现；本波生成完成前不会重叠启动第二波。

`Z` 会遍历 F6/天使蓝线共用白名单中的射手，尝试在每株射手后方（左侧）一格种下天使版向日葵。`X` 会尝试在每株射手前方（右侧）一格种下巴蒂斯特版火炬树桩。目标格越界、已有同层植物或不满足地形条件时会自动跳过，不会覆盖现有布置。

解冻事件只支持 Bob、莱因哈特巨人和死神小丑，包括本次冻结期间刚放置的角色：Bob、莱因哈特在解冻后 `1.5` 秒投掷小鬼，死神小丑在解冻后 `1.5` 秒直接爆炸。

本工具不再使用 `SceneTree.paused`；P 冻结全部已编组角色，Q/W/E/R/T 只控制对应组，未编组角色、卡槽、铲子和导演 UI 始终运行。
