# 游戏内数值调整

从主菜单进入“开发者模式”，点击“数值调整”即可打开。

数值调整使用“改版图鉴”结构：索引页按卡片分页展示全部植物和僵尸；点击卡片进入角色详情后，左侧调整玩法数值，右侧保留原图鉴的角色展示、名称、描述、参数和简介。

## 可调整范围

编辑器会读取角色场景中植物、僵尸及其组件已经导出到角色面板的玩法数值，包括：

- 本体与防具血量；
- 子弹伤害、攻击间隔、僵尸啃食伤害、移动速度；
- 数值型数组和玩法开关；
- 改版角色自己开放的特殊参数，例如 76 豌豆射手的回血、Daotian 三线豌豆的三路线伤害与子弹速度、Mercy 向日葵的蓝线增伤倍率。

角色详情最上方统一使用“基础参数”分组，集中显示本体/防具血量与直接伤害值。普通射手即使场景中使用 `-1` 表示沿用子弹默认伤害，面板也会解析并显示该子弹的真实伤害；三线独立伤害同样会把未覆盖的路线解析为默认伤害。

倭瓜压击、玉米加农炮爆炸、巨人僵尸对被魅惑僵尸的重击等原本写死在专属流程中的数值，已通过角色或攻击组件暴露到“基础参数”。缠绕水草、冰车碾压、巨人对植物整格压扁等本身属于处决机制，不伪装成普通伤害值，仍保留原玩法。

角色类型、初始化状态、动画运行状态、音效枚举等结构性字段不会显示，避免误改角色身份或状态机。

## 保存与生效

点击“保存并应用”后，调整写入：

```text
user://numerical_adjustments.json
```

保存值只会在开发者模式进入的自定义关卡，以及地图工坊“立即试玩”的关卡中生效。普通冒险、迷你游戏和普通入口进入的自定义关卡始终使用项目默认数值。

开发者关卡中新种植或新生成的角色会使用新数值。应用发生在角色和组件 `_ready()` 之前，所以血量、计时器、攻击组件都会用调整后的值初始化。已经存在于场上的角色不会被中途改写。

“重置当前角色”只移除当前角色的调整并恢复项目默认值，不影响其他植物或僵尸。

## 扩展规则

新角色或旧角色新增面板数值后，无需修改数值编辑器：只要字段是导出的 `bool`、`int`、`float` 或非空数值数组，它就会自动出现在对应角色页面中。
