# 玩家存档位置

导出后的游戏使用便携数据。玩家第一次保存后，游戏可执行文件旁只会生成两个分类文件夹：

```text
存档/
开发者包/
```

`存档/` 可以包含多个玩家存档，保存用户列表、各玩家的全局进度、设置和单局续关数据。`开发者包/` 可以包含多个开发者包，同时保存当前关卡工坊数据、正式关卡覆盖、植物/僵尸数值调整和录制布景。导出与导入开发者包时，文件选择器默认打开这个文件夹；自动备份使用时间命名，不会覆盖已有包。

分发 ZIP 后，玩家只要整体移动或备份游戏文件夹，就能连同这两类数据一起移动或备份。

Godot 编辑器运行项目时使用 `user://存档/` 和 `user://开发者包/`，不会在仓库根目录生成测试数据。新版首次读取旧版 `user://` 或游戏旁旧 `user_data/` 数据时，会把已知内容复制到这两个分类；迁移只补充缺失文件，不覆盖新文件，也不删除旧数据。

如果玩家把游戏解压到无写入权限的目录（例如 Windows 的 `Program Files`），程序会回退到系统 `user://`，此时数据不会跟着游戏文件夹移动。建议解压到桌面、文档、其他普通文件夹或玩家拥有写权限的位置。

关卡工坊的安装包初始模板保存在 `res://data/adventure_levels/` 和 `res://data/formal_adventure_levels/`，玩家保存不会修改它们。点击“恢复所选关卡初始设置”会把对应初始模板重新复制到 `开发者包/` 的当前工作数据中。
